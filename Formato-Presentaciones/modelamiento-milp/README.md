# Modelamiento MILP

Deck Reveal.js de 25 diapositivas sobre formulación de modelos MILP. La fuente editable es [`index.html`](./index.html) y el PDF compilado se publica en [`RP-Modelamiento/Modelamiento-MILP.pdf`](../../RP-Modelamiento/Modelamiento-MILP.pdf).

Incluye notas de orador en las diapositivas 2, 3, 6, 15 y 25. Durante la presentación, pulsa `S` para abrir la vista del presentador.

Para la vista previa, abre `index.html` en VS Code y ejecuta **Live Preview: Show Preview** desde `Ctrl+Shift+P`. Consulta el [README principal](../README.md) para instalar dependencias, usar los controles de Reveal.js y compilar el PDF.
