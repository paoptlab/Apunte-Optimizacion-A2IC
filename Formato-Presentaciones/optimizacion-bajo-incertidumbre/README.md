# Optimización bajo incertidumbre

Deck Reveal.js de 17 diapositivas. La fuente editable es [`index.html`](./index.html) y el PDF compilado se publica en [`RP-Modelos-Avanzados/Optimizacion-bajo-incertidumbre.pdf`](../../RP-Modelos-Avanzados/Optimizacion-bajo-incertidumbre.pdf).

La presentación usa `nb-data.js` y `charts.js` para reproducir los resultados del notebook solución. Regenera esos datos desde la raíz del repositorio con:

```bash
python Formato-Presentaciones/actualizar_presentacion.py
```

Para la vista previa, abre `index.html` en VS Code y ejecuta **Live Preview: Show Preview** desde `Ctrl+Shift+P`. Consulta el [README principal](../README.md) para instalar dependencias, usar los controles de Reveal.js y compilar el PDF.
